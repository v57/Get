# Keyboard Shortcuts

<!-- platforms: macos -->

Get has few shortcuts of its own; most actions are buttons on a download's row, in the toolbar and in the row's
menu (Control-click).

## Windows and settings

| Shortcut | Action |
|---|---|
| **⌘N** | New window |
| **⌘,** | Settings |
| **⌘W** | Close the window |
| **⌘Q** | Quit Get. Running downloads continue at the next launch ([Managing Downloads](Managing-Downloads.md#what-get-keeps-when-you-quit)). |

## The Download a Link sheet

| Shortcut | Action |
|---|---|
| **Return** | **Download** (when the link and checksum are valid) |
| **Esc** | **Cancel** |
